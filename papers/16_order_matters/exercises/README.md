## 提示

**遇到困难？**
1. 查看代码注释中的提示
2. 阅读主 README.md，复习概念
3. 查看 PAPER_NOTES.md 中的类比
4. 运行参考解答，了解预期输出
5. 将你的代码与 solutions/ 中的实现比较

**常见问题：**
- **注意力产生 NaN：**检查屏蔽逻辑。softmax 前可用无穷值表示屏蔽，但要排查除以零；整行均被屏蔽时也可能产生 NaN。
- **模型学不动：**先尝试较小集合（5-10 个元素）
- **内存问题：**减小批大小，或使用梯度累积
- **训练缓慢：**有 GPU 时使用 GPU，或减小 hidden_dim
