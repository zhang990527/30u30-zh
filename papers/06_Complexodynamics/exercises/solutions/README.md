# 第 6 天参考解答

第 6 天 Aaronson《复杂动力学第一定律》（2011）练习的参考解答。

**先独立尝试，遇到困难后再查看。**这些解答用于帮助你突破障碍，而不是跳过练习。

| # | 文件 | 对应练习 |
|---|------|----------------------|
| 1 | `solution_01_gzip_complexity.py` | 用 gzip 近似 KC：已知信号测试、压缩等级比较 |
| 2 | `solution_02_coffee_mixing.py` | 咖啡混合模拟：创建网格、交换机制、收集快照 |
| 3 | `solution_03_multiscale.py` | 多尺度分析：各尺度粗粒化、Trevisan 热图 |
| 4 | `solution_04_two_part_codes.py` | 两段式编码：精致复杂度代理量，简单/随机/结构网格验证 |
| 5 | `solution_05_measures_comparison.py` | 比较全部度量：gzip、粗粒化 KC、精致复杂度、边界比例、熵 |

各解答按需从上级目录的 `implementation.py` 导入实现。
