## 关键实现细节

### 解答 1：注意力
- 使用无偏置的 `nn.Linear`，使数学形式更简洁
- 使用 Xavier 初始化提高训练稳定性
- 在 softmax 前用 `-inf` 正确屏蔽

### 解答 2：编码器
- 打包序列，提高 RNN 处理效率
- 将双向输出投影到单一隐藏维度
- 正确处理可变长度序列

### 解答 3：解码器
- 在 GRU 更新之前计算注意力（Bahdanau 风格）
- 组合隐藏状态、上下文与嵌入来生成输出
- 支持逐步与完整序列两种模式

### 解答 4：训练
- 使用带 `ignore_index=0` 的 CrossEntropyLoss 忽略填充
- 使用 `max_norm=1.0` 的梯度裁剪
- 推理时采用贪心解码

### 解答 5：可视化
- 使用 matplotlib 绘制热力图
- 计算注意力熵（越低表示越集中）
- 检查反对角线模式

## 学习要点

完成全部解答后，你应理解：

1. **注意力为何有效**——动态关注输入中的相关部分
2. **对齐问题**——将输出位置与输入位置对应
3. **双向编码**——来自两个方向的上下文
4. **教师强制**——训练时使用真实目标
5. **注意力可视化**——解释模型学到了什么
