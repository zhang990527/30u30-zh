# 练习：从零构建 Bahdanau 注意力

这些练习按照原论文的结构，带你逐步
构建完整的注意力机制。

## 练习 1：加性注意力

**核心机制**

实现注意力评分函数：
```
score(s, h) = v^T * tanh(W_s * s + W_h * h)
```

你将学到：
- 为什么称为“加性”（将变换后的向量相加）
- 如何计算注意力权重
- softmax 归一化的作用

## 练习 2：双向编码器

**双向编码**

构建从两个方向处理源序列的编码器：
- 正向：左 -> 右
- 反向：右 -> 左

你将学到：
- 为什么双向上下文有助于注意力
- 如何用打包序列提高效率
- 如何组合正向／反向隐藏状态

## 练习 3：注意力解码器

**基于注意力的解码器**

实现具备以下步骤的解码器：
1. 在编码器输出上计算注意力
2. 创建上下文向量
3. 将上下文与输入组合，用于预测

你将学到：
- 注意力与 GRU 如何交互
- 训练中的教师强制
- 逐步解码与完整序列解码的区别

## 练习 4：训练循环

**完整流程**

完成反转任务的训练循环：
- 带屏蔽的损失计算
- 梯度裁剪
- 验证与准确率计算

目标：在序列反转任务中**达到 >90% 的准确率**。

## 练习 5：可视化

**注意力可视化**

创建注意力热力图：
- 可视化反对角线模式
- 分析注意力熵
- 用可视化调试模型行为

## 常见问题

### “形状不匹配”
- 检查批次维度的处理
- 检查 squeeze/unsqueeze 操作
- 打印每一步的形状

### “注意力权重之和不为 1”
- 确认 softmax 应用于正确维度
- 检查屏蔽实现

### “训练损失不下降”
- 检查梯度流（查看 .grad 属性）
- 尝试更小的学习率
- 检查损失是否忽略填充位置

注意力机制在现代深度学习中广泛使用。理解它能为学习许多后续架构打下基础。
