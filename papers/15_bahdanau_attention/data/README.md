# 数据目录

本目录说明 Bahdanau 注意力实验所用的数据。

## 玩具数据集：序列反转

为了学习注意力，我们采用合成的**序列反转**任务：

```
输入：[5, 3, 8, 2, 1]
输出：[1, 2, 8, 3, 5]
```

### 为何使用这个任务？

1. **易于验证**——可以立即检查是否正确
2. **注意力模式清晰**——应形成反对角线
3. **无需外部数据**——即时生成
4. **训练较快**——原仓库预期约 30 轮收敛，具体需运行验证

### 特殊词元

| 词元 | ID | 用途 |
|-------|-----|---------|
| PAD   | 0   | 为批处理填充 |
| SOS   | 1   | 序列开始 |
| EOS   | 2   | 序列结束 |
| Data  | 3+  | 实际序列取值 |

## 真实数据集

对于实际机器翻译，可考虑：

### 小型数据集（用于学习）
- **Multi30k**——30k 个英德句对
- **Tatoeba**——社区翻译的句子
- **IWSLT**——TED 演讲翻译

### 大型数据集（用于研究）
- **WMT**——机器翻译研讨会数据集
- **Europarl**——欧洲议会议事记录
- **OpenSubtitles**——电影字幕

## 生成数据

训练脚本自动生成数据：

```python
from train import ReversalDataset

# 创建数据集
dataset = ReversalDataset(
    num_samples=5000,
    min_len=4,
    max_len=10,
    vocab_size=50
)

# 获取一个样本
src, trg = dataset[0]
print(f"源序列：{src.tolist()}")
print(f"目标序列：{trg.tolist()}")
```

## 数据格式

每个样本是包含以下内容的元组：
- `src`：源序列张量（不含特殊词元）
- `trg`：目标序列张量（含 SOS 和 EOS）

批次整理函数负责：
- 填充至相同长度
- 创建用于序列打包的源长度张量
