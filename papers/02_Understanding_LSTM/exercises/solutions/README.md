## 学习建议

### 比较自己的解答时

关注以下方面：

1. **正确性**：是否产生正确输出？
2. **效率**：是否存在不必要的循环？
3. **可读性**：其他人能否理解代码？
4. **注释**：是否解释了原因，而不只是描述操作？
5. **边界情况**：是否处理空输入、NaN 等情况？

### 检查常见错误

- 遗忘门偏置没有初始化为 1
- 混淆细胞状态（C）与隐藏状态（h）
- 没有裁剪梯度，可能造成梯度爆炸
- 混用 sigmoid 与 tanh
- 矩阵运算形状不匹配
- 在自动微分实现中没有在序列边界切断状态梯度；本章 NumPy 实现显式管理梯度
